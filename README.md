# Everpool — landing

Static landing page for **Everpool**, a token launchpad on pools.trade where a token's
trading fees are folded back into its own pool every ten minutes.

Single self-contained file: [`index.html`](index.html) (embedded fonts, WebGL background, no build step).

## Deploy on Vercel
Import this repo at [vercel.com/new](https://vercel.com/new) → framework preset **Other** →
**Deploy**. No build command needed; it serves `index.html` at the root.
